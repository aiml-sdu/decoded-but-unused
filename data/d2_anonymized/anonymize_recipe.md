# D2 anonymization recipe

Goal: remove AoT-specific entity priors from the model's input.

## Builder
`shingeki/data/curate_d2.py` applies the deterministic mapping in `name_map.json`
to all 40 D0 triplets. The output is `aot_anonymized.jsonl`. Re-run with:

```
shingeki data build-d2
```

## Mapping principles
- Personal names → role labels with single-letter discriminator (e.g. "Eren" → "Leader A").
- Group / nation names → "Group X", "Nation Y".
- Faction proper nouns → generic role descriptions ("Survey Corps" → "Reconnaissance Corps").
- Iconic concepts → functional descriptions ("the Rumbling" → "the mass-deployment weapon").
- Walls and place names → generic spatial labels.

## Adding entries
Edit `name_map.json`. Keys are matched with `\b<key>\b` regex on each scenario.
Longest keys are tried first so multi-word entries take precedence.

## Manual curation
After `build-d2`, audit the output: ad-hoc references that the regex misses
(possessive pronouns, paraphrases) need hand-fixes. The expected workflow is to
treat the autogenerated output as a draft, copy any rows that need editing into
this directory by hand, and add a note in this file recording what required
human intervention.
